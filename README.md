# 🕺💃 Танцевальный Календарь Бот

Telegram бот для управления танцевальными мероприятиями с интеллектуальным парсингом自然ного языка и системой напоминаний.

## 🌟 Особенности

### 🎯 Основной функционал
- **Умный парсинг** - понимает естественные описания мероприятий
- **Автоматические напоминания** - уведомления за 24 часа до события
- **Общий календарь** - все пользователи видят все мероприятия
- **Московский часовой пояс** - корректная работа с временем

### 👑 Функции для администраторов
- **Массовая рассылка** - уведомления всем пользователям бота
- **Управление событиями** - просмотр и удаление любых мероприятий
- **Статистика** - подробная аналитика использования бота
- **Отладка** - полный просмотр базы данных

## 🚀 Быстрый старт

### Для пользователей
1. Начните с команды `/start`
2. Добавляйте мероприятия через кнопку или отправляя текстовое описание
3. Получайте автоматические напоминания за день до события

Примеры описаний:
- "Завтра в 19:00 в Троицком танцуем вальс"
- "В субботу в 20:30 в ДК Железнодорожников сальса и бачата"
- "Послезавтра в 18:00 - танго в парке Горького"

### Для администраторов
Доступны дополнительные команды через меню:
- 📢 Рассылка напоминаний
- 🗑️ Удаление событий  
- 🔧 Просмотр всех данных
- 📊 Статистика бота

## 🛠 Технические детали

### Архитектура
- **Python 3.9+** с библиотекой python-telegram-bot
- **PostgreSQL** на Render (или SQLite локально)
- **APScheduler** для планирования напоминаний

### База данных
Хранит:
- События (дата, место, танцы, создатель)
- Пользователей бота (все, кто запускал /start)
- Мета-информацию для статистики

### Парсинг
Автоматически извлекает из текста:
- 📅 Дату и время (сегодня, завтра, конкретные даты)
- 📍 Место проведения
- 💃 Виды танцев
